# objects/ — the nouns

One card per noun, clustered by the question an editor asks (see `../CONTEXT.md`). `_index.md` is generated; open a card from it.

Reads: the source file each card names. Writes: nothing; a card is a pointer with a waterfall. Human check: `Hits` / `Does not hit` against the code before trusting it for a change.

To add a noun: copy `../_templates/object.md` into the cluster, cite source, run `../_meta/rebuild.sh`.
