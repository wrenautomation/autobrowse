# One verb: `do`

## Decision (William, 2026-09-21)

"Everything should be easy to interface with in future code: 'upload this
to youtube', 'do this thing in browser', 'deploy this on cloudflare
workers' should be easy and convenient, not like now where everything is
done manually." One entry, from a terminal, from code, from an agent.

## Shape

- `do({goal, inputs?, site?, url?, dryRun?}) → {via, name, input, output,
  status, built, session, summary, usage}` (`src/do/doer.ts`).
- Abilities (`src/do/catalog.ts`): every site route with how it answers now
  (`ready`, `missing`), every compiled workflow with its plan fields, every
  hand-written flow. `autobrowse abilities`, `GET /api/abilities`.
- Pick (`src/do/pick.ts`): an exact name is a match with no model; else the
  model maps the goal and the named inputs onto one ability and its input,
  or none plus the site to explore. A picked name not in the list is none.
- Run: site → `sites.call`; workflow → `runCompiled` in-process (gates hold:
  `waiting` answers `needs-human`); flow → the runner.
- Nothing ready → the agent (`AgentSessions.start`), settled the way the
  builder settles; achieved → saved and compiled under the missing leg's
  workflow name (`workflow x not recorded` → `x`) or a slug of the goal.
  Next ask finds a ready ability. `needs-human` leaves the session open in
  Explore; failed closes it.
- Doors: CLI `do`/`abilities`; `POST /api/do` (a `Jobs` job, `dryRun`
  synchronous); Restate `do/run` (one `ctx.run`, one attempt: a goal that
  publishes never runs twice); MCP tool `do`. wren: `autobrowseDo` (HTTP,
  waits on the job) and `restateDo(ctx, wake)`.

## Rules

- The verb never bypasses a gate: a purchase or a publish the caller did
  not gate waits for a person inside the leg, as before.
- No model → exact names only; anything else is 501 with the reason.
- The picker's usage counts against the model budget like every call.

## Where to attack (ranked)

1. ✅ Proven locally 2026-09-21: `do "what is my youtube channel called"`
   with `LLM_PROVIDER=claude-code` picked `youtube GET /youtube/v3/{resource}`
   with `{resource: channels, mine: true, part: snippet}` and answered
   JinstersJournal. The first pick stuffed the query into the path param;
   fields now carry `(path: a|b)` / `(boolean)` hints. Still open: a goal
   with nothing ready (agent → compiled) once a model key is funded, and
   the same on the box (its LLM is the Anthropic key, dead until funded).
2. ✅ (2026-09-21) The polish pass proposes a camelCase name for each plan
   field whose key is opaque (`field1` → `projectId`); `renameField` carries
   it to every fill/type/upload that reads it and every `{key}` in a step
   URL; a taken or invalid key is ignored (`src/compiler/polish.ts`).
3. ✅ (2026-09-21) Ability kind `tool` (`src/do/tools.ts`): a tool names
   its binary, inputs and command line (values shell-quoted), runs in the
   input's directory through the worker's shell; ready when the binary is on
   the PATH, else `missing` says how to install it. Built in:
   `wrangler-deploy`, `gh-pr-create`, `ffmpeg-convert`. `do` answers the
   exit code and the output's tail. Open: the desktop leg's apps as sites
   (`designs/2026-09-21-desktop-leg.md`).
4. ✅ (2026-09-21) Pick memory (`src/do/memory.ts`): `goal → ability` pairs
   the model chose (exact names are not kept) go to
   `recordings/.do-picks.json` and the last 20 are shown to the picker as
   EARLIER PICKS.
