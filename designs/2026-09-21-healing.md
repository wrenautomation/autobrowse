# Workflow healing

William, 2026-09-21: the workflows we built (Google, Cloudflare, …) are first
class; there should be a first-class healing / editing feature; maybe
determinism with failure handling that switches to explore.

## Decision (built 2026-09-21)

Deterministic first, explore only at the break, deterministic again after.

1. A compiled step fails (a locator miss the one-shot repairer could not fix,
   a page that changed). The runner writes the failure record as before and
   now also hands it to `App.onFailure`.
2. Heal (`src/agent/heal.ts`): find the compiled workflow whose step is the
   failed flow (steps are named after their flows; hand-written workflows have
   no `outline.json` and are reported, not touched). Start an agent session
   from the record: same page URL, goal "finish what the flow was doing".
3. The agent's journal is saved as `<workflow>-heal-<step>`, structured, and
   its ops replace that one step's ops in the workflow's outline. Fields and
   secrets the repair introduced join the plan. Everything else stays.
4. The outline is saved beside the compiled module (compiling now writes
   `outline.json` there too: it is the editable source), the module is
   re-rendered, and the workflow is proven once. `healed` needs a passing proof;
   otherwise `proof-failed` with the line, and the outline is still there to edit.
5. A step the agent cannot finish alone (`needs-human`) stays a paused session
   the person finishes in Explore; nothing is rewritten.

Surfaces: `AUTO_HEAL=true` in the worker (one heal at a time per site/flow;
only `kind: failed`, never a person's step or an interrupted browser leg);
`autobrowse heal <failure>`; "heal step" beside "repair with agent" on a run;
`POST /api/agent/heal`. Every outcome is a channel note.

## Editing

`outline.json` beside each compiled workflow is the edit surface (the only
copy; the recording dir holds none): change an op, a hint, a step's URL.
`PUT /api/workflows/:name/outline` validates, saves and re-renders through
`rerender` (the same path a heal takes); the Workflow page in the UI
(`#/workflows/<name>`, linked from Runs and from a fresh compile) is that
editor. `autobrowse compile <name> --from-outline` does it from the CLI.

## Why not "switch to agentic and stay there"

The flow's value is that it runs with no model. Healing spends one agent
session per break and returns to zero-model runs, with the proof as the gate.
