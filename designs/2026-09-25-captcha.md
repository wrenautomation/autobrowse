# Captcha solver

William allows the agent to solve captchas, picture ones included
(2026-09-25). It lives beside the hands: `src/browser/captcha`, which
imports only Playwright types and `../human`.

## Shape

- `findCaptcha(page)` → `{kind, vendor}` or null. An open challenge is
  checked before its checkbox. Vendors: reCAPTCHA, hCaptcha, Turnstile,
  generic (a captcha picture beside an input, a slider).
- `solveCaptcha(page, {hands, eyes})` runs up to 6 rounds:
  - checkbox: one human click, wait for the tick, a challenge, or the
    Turnstile token.
  - grid: photograph the challenge box, ask the eyes for
    `{"squares":[…]}`, click them, look again while "none left", Verify.
  - text: ask for `{"text"}`, type it; the flow submits its own form.
  - slider: ask for `{"pixels":n}`, drag.
- `Eyes` = any model that sees. `eyesOf(llm)` sends the PNG as an image
  block (Anthropic, OpenAI, claude-code via stream-json; Cohere refuses).
- Pictures are element screenshots in memory; nothing is written to disk.
- A throw (a model that cannot see, a moved part) returns unsolved with
  the reason; it never crashes the flow.

## Where it runs

- `fp.captcha()` runs up to `CAPTCHA_ATTEMPTS` whole solves (default 3;
  0 = straight to a person). No retry when nothing is there or a picture
  has no eyes.
- The runner: a captcha wall on `open` gets `fp.captcha()` before `NeedsHuman`.
  Every runner gets `captcha: captchaFor(settings)`.
- Flows: `fp.captcha()`.
- Explore: `{"cmd":"captcha"}`; the explorer agent has the same action.

## Where to attack

1. Untested on a live challenge. Selectors are from vendor docs, not
   mapped pages. First real hit: map it in explore, fix selectors.
2. Grid answers from one picture of the whole grid. A 4×4 reCAPTCHA
   (one image cut into squares) may need a finer prompt.
3. Slider distance is the model's pixel guess; a wrong one costs a round.

## Codes on a shared phone (same day)

Ten senders text one phone; a "G-123456" names no account. One sign-in
took another's code, and Google locked seven accounts for hours. Now:

- `ctx.serial(kind, fn)`: ask, read and type under an inbox lock (a lock
  dir in tmp; every process on the machine queues; stale after 5 min).
- A code counts only if it arrived after the ask; a typed code is spent.
- "Too many failed attempts" ends the sign-in with that reason.
- The lasting fix is an authenticator per sender (`enroll-totp`), shared
  to Apple Passwords with `creds to-passwords` (one row per login: address, password, authenticator; no manual matching) so William signs in anywhere.
