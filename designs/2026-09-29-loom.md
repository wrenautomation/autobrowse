# Loom posting

2026-09-29. Status: built, proven live.

## What

Loom as a site on the facade: `loom`, account william@wrenautomation.com
(signs in via Google), workspace `wrenautomation`.

| Route | Leg | Does |
|---|---|---|
| `GET /videos/{id}` | api (oEmbed, open) | title, duration, thumbnail, embed html |
| `POST /videos` | browser `loom/upload` | file (path or URL) + title → `{id, url, title}` |
| `PATCH /videos/{id}` | browser `loom/rename` | retitle |
| `DELETE /videos/{id}` | browser `loom/delete` | delete for good (irreversible) |

The share link is the post: public to anyone who has it, never indexed.

## Decisions

1. **Browser legs for writes.** Loom has no API for a video's owner; its
   SDK records inside a page, and oEmbed only reads. The web app's upload
   dialog takes a file input, so the flow is short and stable.
2. **oEmbed for reads.** Open, keyless, official. A deleted video answers 404.
3. **No wren channel.** Loom has no feed or audience. A Loom link is
   something other channels carry (email, a post), not a channel itself.
   wren calls `sites/call loom POST /videos` when it needs a link.
4. **Caps low: 10 uploads a day.** Starter (free) keeps 25 videos a person
   and caps recordings at 5 minutes after the 14-day trial. Old videos get
   deleted, or William upgrades (his spend).
5. **Upload is not gated; delete is.** An upload is reversible and reaches
   no one by itself. Delete kills a link someone may hold.
6. **Title after upload.** A fresh upload opens its share page with the
   title box focused and empty; an older one shows a "Rename video" button.
   `rename` takes either.
7. **Error messages lose query strings.** The first sign-in failure printed
   an Atlassian confirmation URL with a token in it. `LoginFailed` and
   `NeedsHuman` now pass their message through `safeUrls` (origin + path).

## Proven

- Account made (Google → Atlassian "Create your account" → workspace).
- `site call loom POST /videos` with a 3 s clip + title → share link, title set.
- `PATCH` retitled; `GET` read it; `DELETE` removed all three test videos
  (oEmbed then 404).
- `autobrowse login loom` → signed in.
