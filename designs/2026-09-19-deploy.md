# Deploying autobrowse

Same code, three shapes. Nothing in the image is a secret; the worker
reads everything from the environment and registers itself with Restate.

## Local (today)

`pnpm worker` next to wren's local Restate (`localhost:8080/9070`), UI on
`:9080`. `.env` holds the keys. `RESTATE_ADMIN_URL` +
`RESTATE_ENDPOINT_URL` make the worker register itself; without them,
`restate deployments register http://localhost:9081` by hand.

## Docker Compose

`docker compose up --build`: Restate + worker, `.env` as `env_file`, a
volume at `/data` for profiles (logins), artifacts (traces, screenshots)
and recordings. The image is Playwright's, so `BROWSER=local` works headless
inside it; `BROWSER=browserbase` needs no Chromium at all. A headed
recording is still a laptop job (`pnpm autobrowse record`), the recording
directory is then mounted or copied in.

## AWS / Kubernetes

- Image to ECR from CI (same Dockerfile).
- Restate: Restate Cloud (the wren env) or a self-hosted `restate-server`
  StatefulSet with a PVC. The worker's `RESTATE_ENDPOINT_URL` is its
  Service DNS; with Restate Cloud, `restate cloud env tunnel` or a public
  endpoint plus request-signature validation (SDK env `RESTATE_IDENTITY_KEYS`).
- Secrets: one Kubernetes `Secret` (or SSM/Secrets Manager via External
  Secrets) projected as env, exactly the names in `.env.example`. The
  Google service account is a mounted file, `GOOGLE_SERVICE_ACCOUNT` points
  at it.
- State: a PVC at `/data`. Persistent browser profiles are per-site
  directories, so one replica per site lock is the rule: run one worker
  replica, or move to `BROWSER=browserbase` where the context lives on
  their side and replicas can scale.
- Ingress: the UI on `:9080` behind auth (`UI_TOKEN` is required before it
  is reachable off loopback; the server refuses to bind wider without one).
- Lambda is not a fit for this worker (long browser sessions, persistent
  profiles); wren's Lambda shape stays wren's.

## What is not containerized

Headed recording and site logins: a person does them once on a machine
with a screen. Everything after (`compile`, runs, gates) runs anywhere.
